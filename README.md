* controller color control

   ## 1.2. Proxy Generator 

<img src= "./assets/Proxy Generator.Png" width = 400>


The proxy generator is a maya plugin tool that allows the user to recall proxies which in turn enables you to toggle on and off different parts of a rig. Esentailly breaking down the rig into chunks.

* checks to see if the models mesh has skin, and joints

* Creates a sort of build connections for all the joints, and the parented skin

* Generates the proxy nodes needed

* Check for any joints with influences on them
